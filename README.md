# Dragon Dungeon Programming 1
This is a repository for the final project for computer programming 1. 
We will be making a game called Dragon Dungeon.
We are making a Dragon Quest-esque game with an overworld system and battle system.  


![DragonQuest1MonsterEncounter](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcRgewV56-6nhVM2gWKZDM_pm1DEjCuebvA5EI6X4PIOog&s=10)
                                                                                                                
## Game Overview          
It will be like a dungeon crawler, but closer to Pokemon than Zelda.
Our target audience would be teens, or anybody who is interested in JRPG's. and our goal is to create a game that will let you explore the world we create and fight monsters that spawn in encounter screens.
One feature we will implement is WASD movement which lets you move around the over world, and mouse use to select an action during the battle sub-screen,.
The smallest working version would be a character walking along a flat 2-D plane and encountering a monster, which the player could then fight.
A question we have decided to ask is how many monster types do we incorporate, and which monsters should we do? Should we do traditional fantasy monsters or original monsters?  The primary thing we need to research is how to get a battle screen to overlay the over world screen while pausing the over world screen.
