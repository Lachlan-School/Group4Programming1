# Group4Programming1
This is a repository for the final project for computer programming 1. 
Our game will be called Dragon Dungeon.
We are making a Dragon Quest-esque game with an overworld system and battle system.                          
![Dragon Quest 1](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcRgewV56-6nhVM2gWKZDM_pm1DEjCuebvA5EI6X4PIOog&s=10)
It will be like a dungeon crawler, but closer to Pokemon than Zelda.
the people that would play would be teens to adults.
Our goal is to create a game that will let you explore the world we create and fight monsters that spawn in encounter screens.
WASD movement
The smallest working version would be a character walking along a flat 2-D plane and encountering a monster.
