# Group4Programming1
This is a repository for the final project for computer programming 1. 
Our game will be called Dragon Dungeon.
We are making a Dragon Quest-esque game with an overworld system and battle system.                          
![DragonQuest1MonsterEncounter](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcRgewV56-6nhVM2gWKZDM_pm1DEjCuebvA5EI6X4PIOog&s=10) ![DragonQuest1Overworld](https://www.google.com/imgres?q=dragonquest%201&imgurl=https%3A%2F%2Fwww.oldgamehermit.com%2Fwp-content%2Fuploads%2F2020%2F05%2FDWNES.png&imgrefurl=https%3A%2F%2Fwww.oldgamehermit.com%2F2020%2F05%2Freview-dragon-quest%2F&docid=EXM-HpgasqoE3M&tbnid=-noCq2U8w9FfPM&vet=12ahUKEwie66anq9-XAxXVJUQIHemkHeQQnPAOegUIlwEQAA..i&w=1193&h=1080&hcb=2&ved=2ahUKEwie66anq9-XAxXVJUQIHemkHeQQnPAOegUIlwEQAA)
It will be like a dungeon crawler, but closer to Pokemon than Zelda.
Our target audience would be teens to adults, and our goal is to create a game that will let you explore the world we create and fight monsters that spawn in encounter screens.
One feature we will implement is WASD movement, and the smallest working version would be a character walking along a flat 2-D plane and encountering a monster.
A question we have decided to ask is how many monster types do we incorporate?
